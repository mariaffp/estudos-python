# Estudos Python



Notebooks desenvolvidos durante o curso técnico de Informática para análise de dados.

Conteúdo sendo atualizado aos poucos no GitHub, abrange desde a introdução aos conceitos e funções em python até ao uso de numpy e pandas. 

Notebooks:

exercícios_python_while.ipynb
24 exercícios com laços while, indo do básico (contar de 1 a 10) até problemas com loops, como gerar tabuadas de 1 a 10 e filtrar pares de números por condição matemática.

Funções_python_introdução_MF.ipynb
Introdução a funções: parâmetros, retorno de valores e reaproveitamento de código. Os exercícios cobrem desde saudações simples até contagem de vogais em strings.

Listas_conceito.ipynb
Exploração do tipo list do Python, abrangendo criação, acesso por índice, fatiamento, métodos como append(), remove(), insert(), e o comando del. Mistura teoria com exemplos práticos.

Numpy_Maria_Fernanda.ipynb
Introdução ao NumPy: diferença entre listas e arrays, operações vetorizadas, fatiamento, estatísticas básicas (mean, max, sum) e geração de números aleatórios. Inclui exercícios aplicados, como análise de temperaturas e simulação de dados de sensores.


Tecnologias:

Python 3
NumPy
Google Colab
